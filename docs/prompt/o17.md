## 核心主题

原视频可辨识画面文字整理。节录、遮挡和重复表述的处理，见下方来源说明。

## 提示词与使用说明

来源 V3 03:38附近。以下为画面里的用户输入，保留原有口语和英文拼写。

```prompt
我想做成2分钟的分镜头，但是每个镜头不要很长大概2s3s这样我们做一个分镜头吧，按照这个样式来做，给我exel。
```

复用提示：这个示例说明要同时给时长、单镜头长度和表格样式。原画面回复提到48个镜头、每镜2或3秒、总长120秒，并包含表演细节。不要把2至3秒当成所有剧情的通用镜头长度，较长对白和反应需要另行安排。

## 注意点

原例中的时代、地域、人物比例、肤色、时长与摄影要求只对对应项目生效。使用时先确认镜头任务，避免混用角色卡、空场景与正式剧情镜头的限制。
