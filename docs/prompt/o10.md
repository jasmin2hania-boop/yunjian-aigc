## 提示词与使用说明

来源 V2 02:23附近、V1 04:40附近。节录表演和光源关系部分。

```prompt
爷爷一只手自然搭在沙发扶手或靠垫附近，另一只手松松放在腿上，身体几乎没有动作，只是安静地看着正前方画外的电视机。他的神情比较呆滞、迟缓、微微出神，眼睛虽然停留在电视方向，却没有明显投入节目，像只是在维持“坐在这里看电视”这个动作。不要演成痴呆，不要明显悲伤，不要皱眉、哭泣、叹气或睡着，只允许非常缓慢的眨眼、轻微呼吸和极细微的视线变化。

电视机必须位于爷爷正前方、靠近摄影机视线方向的位置，作为明确的画外光源。电视正在正常播放节目，屏幕画面不断发生变化，因此爷爷的脸、眼睛、鼻梁、脸颊、全白头发以及灰色长袖前胸会出现非常自然的电视屏幕反射光。电视光以偏冷的蓝灰、灰白色为主，但随着节目内容偶尔出现极轻微的亮度和色温变化：有时脸稍微亮一点，有时又暗下来，偶尔掠过一点非常弱的偏暖或偏蓝反射。变化一定要缓慢、随机、真实，不能像警灯一样频繁闪烁，不能强烈跳色，不能制造恐怖片式闪光。

电视冷光主要照到爷爷脸部正面和眼睛，形成一种微弱、不断变化的正面补光；室内暖色台灯或落地灯则从侧后方提供稳定的暖色环境光。形成明确的双重光线关系：侧后方是稳定、柔和的暖色家庭灯光，正前方是不断轻微变化的电视冷光。暖光包裹住沙发、白发边缘和房间家具，电视冷光则轻轻浮动在爷爷的脸上，让人物始终处于一种暖环境与冷屏幕之间的状态。白发高光一定要压住，不能过曝发光，皮肤仍保留毛孔、皱纹、眼袋、晒斑和真实老年肤质。
```
