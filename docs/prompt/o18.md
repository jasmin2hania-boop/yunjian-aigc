## 提示词与使用说明

来源 V3 04:26附近。以下为画面顶部可辨识的提示词节录。

```prompt
生成一段4秒、1:1正方形画幅的叙事电影镜头。一镜到底，正拍，摄影机沿真实滑轨平稳向前推进，从远景自然过渡到全景。全程保留祖孙完整身体、板凳、脚下地面及周围庭院，不推进成中景、近景或特写。摄影机真实改变位置，产生自然视差。
```

复用提示：这一例子强调移动的起点、终点和不能越过的景别边界。模型是否完成真实感视差，需要看生成结果，不能由提示词文字直接推定。
