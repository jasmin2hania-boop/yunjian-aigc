## 提示词与使用说明

来源 V2 01:25至01:27附近。开头受水印遮挡，从可辨识的场景占位符起节录。

```prompt
场景为【具体场景名称】，时间为【白天／傍晚／夜晚／阴雨】。画面严格只保留环境，不出现任何人物、人体局部、倒影、剪影或模糊人影。

整体首先必须像真实摄影机在真实空间中拍摄到的环境，而不是概念设计图、游戏场景或AI渲染图。空间结构、建筑比例、道路、墙体、门窗、植物、家具以及生活用品全部符合真实中国环境逻辑，不刻意追求漂亮和整洁，保留长期使用产生的自然痕迹，例如旧墙轻微脱落、灰尘、泥土、木头磨损、金属氧化、布料褶皱、玻璃灰尘、地面裂纹和自然色差，让环境具有“真正有人生活过”的感觉。

整体色彩低饱和、中低反差，以中性自然色为基础，根据时间和情绪允许轻微偏暖或偏冷，高光柔和顺滑不过曝，暗部有密度但绝对不能死黑，阴影中仍然能够辨认墙体、地面、家具和环境材质。自然光必须遵循真实物理逻辑，所有光线都要能够找到明确来源，禁止无来源戏剧光和商业棚拍光。

使用35mm／50mm电影镜头视角，正常成年人眼平高度，保持真实透视关系，不使用夸张超广角，不故意拉伸空间。画面加入非常轻微的 subtle black mist／black pro-mist diffusion，使窗户、灯泡、水面、金属或阳光高光产生克制的光学柔化和轻微 halation，但不能形成梦幻柔焦。

空气不能过于干净透明，空间中存在少量真实悬浮尘埃、水汽、柳絮、煤尘或环境中合理存在的微小颗粒，颗粒随机分布，前景略大且偶尔失焦，中景较清晰，远景逐渐融入空气透视，只在侧光、逆光或局部光源经过时自然显现，形成真实的空气厚度和前中后景关系，而不是特效粒子。

加入细腻、不规则、有机的35mm胶片颗粒，零数字锐化，所有清晰度来自真实光学成像，材质纹理清楚但边缘不过度锐利。整体氛围安静、克制、自然、有呼吸感，避免网红滤镜、旅游宣传片、商业广告和短视频质感。绝对去除鱼鳞纹、油画涂抹感、塑料材质、过度降噪、HDR感、CG感、AI生成感、过度锐化、虚假景深、重复纹理、建筑结构错误和不符合物理规律的光影。
```
