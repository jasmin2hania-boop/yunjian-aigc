## 提示词与使用说明

来源 V2 03:47至03:50附近。

```prompt
人物表演必须保持绝对自然、克制、生活化，像真实摄影机偶然记录到的人，而不是演员在等待指令后完成规定动作。所有情绪都通过真实身体反应逐渐发生，不要一步到位地“演出情绪”。人物先接收到外界信息，再出现极细微的停顿、眼神变化、呼吸变化、嘴唇或下颌轻微动作，随后身体才产生反应，动作之间存在真实的人类延迟和不完全同步。

眼神不能一直盯着同一个位置，允许短暂游移、眨眼、重新聚焦；呼吸要自然，胸口和肩膀有非常轻微起伏。说话时嘴部运动、呼吸、眼神、头部和身体重心不能完全同步，避免机械式“张嘴—说话—闭嘴”。人物可以有无意识的小动作，例如手指轻微收紧又放松、衣角被顺手整理、脚下重心改变、吞咽、抿嘴、鼻翼轻动、轻微皱眉、视线短暂回避，这些动作必须随机、克制、符合当下情境。

情绪不要通过夸张表情直接表达，悲伤不等于立刻哭，开心不等于一直笑，紧张不等于大幅颤抖；真实情绪应更多隐藏在停顿、呼吸、眼神、身体僵硬或动作中断里。人物之间互动必须有“听”的过程，对方说话时不要提前做反应，要先真正听到，再出现反应；不要抢台词，不要同时转头，不要所有人动作整齐一致。

情绪变化必须有过程，例如惊讶可以先停手、再抬眼、再转头；悲伤可以先沉默、呼吸变浅、视线下移，再出现很轻的嘴角或眼眶变化；开心可以先眼神亮起来，再出现轻微笑意，而不是瞬间大笑。整个表演强调真实身体重量、真实惯性、真实节奏和微小的不完美，避免舞台腔、广告式微笑、短视频表演、偶像剧式停顿、夸张肢体、统一节奏、AI机械动作和过度情绪化。
```
