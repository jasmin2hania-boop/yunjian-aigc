## 核心主题

后续分为“画面提示词整理”和“新增复用模板”。先找与你的任务对应的一条，替换角色、时间、场景和动作，再选择一套光线与表演要求。角色卡、空场景、正式剧情镜头是三种不同用途，不要把它们的限制混贴。

例如，角色卡要求白底与自然站立；正式镜头必须让角色进入环境并表演。空场景要求完全无人；正式剧情需要出现人物。原文中的“不加音乐”“固定机位”“北方农村”“过去时”等只对具体镜头生效。

英文术语便于理解：Catchlight 指眼睛里的光源反射；Micro Shadowing 指细微结构形成的小阴影；Peach Fuzz 指皮肤细绒毛；Black Mist 与 Pro Mist 在这里用于描述克制的高光扩散；Halation 指高光附近的晕染描述；Fine Organic Film Grain 指细腻有机胶片颗粒；Zero Digital Sharpening 指不追求数字锐化效果。它们是提示词中的质感表达，不是证明生成图像经过了真实镜头、滤镜或胶片拍摄。
