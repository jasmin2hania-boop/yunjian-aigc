## 提示词与使用说明

来源 V3 04:26附近。画面显示的是平台输入框的示例文字，不能当作完整剧情提示词。

```prompt
例如：@图片1模仿@视频1的动作，音色参考@音频1。
```

复用提示：这段展示的是图片、视频、音频可以被分别指向。实际使用时用当前项目素材选择器产生的真实引用，并逐个写明角色与音色归属。它不能保证任意平台都接受同样的语法。
