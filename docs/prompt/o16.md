爷爷对着海、看着镜头，但不是有意识地“看观众”，而是视线虚弱地落在镜头方向，像前方已经没有太多可分辨的东西。眼神微微失焦、迟缓、空弱，仍保留一点极其细微的清醒。他的眼睛绝对不要突然发光，不要戏剧化闪亮，只允许被海边夕阳和空气反光非常自然、非常克制地轻轻映亮一点点。
