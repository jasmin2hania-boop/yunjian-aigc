## 提示词与使用说明

来源 V2 02:25附近，V1 04:43附近和05:18附近。节录动作与声音部分。

```prompt
镜头开始时，年轻爷爷已经停下手里的活，微微喘着气，胸口有轻微起伏，一只手自然扶着锄头，头轻轻靠在锄头把上，整个人放松下来。远处传来孙子的画外音，平静自然地问一句：“爷，我奶呢？”

听到这句问话后，爷爷不是立刻做夸张反应，而是先有一个非常细微的停顿，眼神轻轻愣一下，像是这句话忽然把他带回某段记忆里，随后嘴角慢慢扬起，露出一个很轻、很自然、很克制的微笑。这个笑要朴素、短暂，带一点怀念，但不要煽情，不要大笑，不要偶像剧式情绪表达，也不要马上回答台词。重点是拍出一个年轻人正在过日子的状态，以及那种被一句话轻轻碰到内心的瞬间。

摄影机使用75mm或85mm电影镜头，胸部以上近景，眼平高度，完全固定机位，不推、不拉、不摇、不移，不要漂浮感，不要稳定器悬浮感，不要短视频感。构图上人物位于画面中心或微偏中心，锄头木柄形成自然竖线，但不能挡住人物五官。

声音设计保留菜地环境底噪、远处蝉鸣、微风吹过菜叶的声音、人物轻微呼吸声和衣料摩擦声，孙子的画外音“爷，我奶呢”平静自然，不要播音腔。整体情绪是非常普通、非常生活的一瞬间，人物还年轻，日子还在继续，但一个轻轻的微笑里已经藏着很多后来的故事。
```
