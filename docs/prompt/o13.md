## 提示词与使用说明

来源 V1 02:40至02:45附近。以下节录四种时间线的核心段落，保留差异化参数，不重复整段通用纹理要求。

```prompt
**回忆片段。**中国北方乡村青年记忆，过去时，盛夏，晴天，自然日光经过轻微柔化，整体明亮、通透、温暖，却不刺眼。画面带有一种被太阳晒过的青春回忆感，参考《阳光灿烂的日子》所呈现的夏日记忆气质，但不要复制具体画面和构图。整体低饱和、中低反差，中性基础上轻微偏暖黄，暖色来自真实阳光而不是后期黄色滤镜。

**命运分岔时间线。**属于过去时夏日记忆系统，但相比前面的青春嬉闹段落，暖黄色明显收敛，色彩逐渐向灰绿、青灰、旧木色、铁路钢铁色靠近。自然光依然柔和明亮，但不再有过度浪漫的金色包裹感，画面中开始出现更明显的阴影、空间纵深和冷色环境反射。整体低饱和、中低反差，中性偏暖，但暖意正在逐渐退去。

**矿难与失去时间线。**中国北方阴雨天气现实主义影像，参考《敦刻尔克》式冷峻、克制、具有重量的空气与色彩关系，但不要复制任何具体画面。天空厚重，太阳被完全遮住，自然散射光成为唯一主光。整体以灰蓝、钢灰、青灰、泥土褐、暗橄榄绿和湿黄土色为主，低饱和、中低反差，冷色占主导，但保留泥土和人物皮肤自身的少量暖色，使画面不是简单套蓝色滤镜。

**现实时间线。**当代中国北方农村现实主义电影影像，室外晴天柔光，自然日光经过轻微柔化处理，整体明亮、通透、真实，但绝对不要有过去时的黄色怀旧滤镜。色彩以中性自然为基础，轻微偏暖，环境空气中允许存在少量冷青灰和蓝灰色，使人物与环境之间形成真实空气透视。整体低饱和、中低反差，高光顺滑不过曝，暗部保留完整细节。
```

复用提示：这一条是章节级规则。先确定同一故事中不同阶段的心理变化，再选择哪些视觉参数随之变化。不要把四段一起贴入同一个镜头。

## 注意点

原例中的时代、地域、人物比例、肤色、时长与摄影要求只对对应项目生效。使用时先确认镜头任务，避免混用角色卡、空场景与正式剧情镜头的限制。
