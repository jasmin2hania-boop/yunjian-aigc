## 提示词与使用说明

来源 V2 03:11至03:12附近；V1 05:54附近重复讲解该方法。

画面空气不能过于干净透明，必须存在真实、自然、具有空间层次的悬浮颗粒，包括极细微灰尘、空气尘埃、轻微水汽、柳絮、煤尘或环境中合理存在的微小颗粒。颗粒大小必须不完全一致，分布随机、不规则，前景颗粒稍大并偶尔失焦，中景颗粒最清晰，远景逐渐融入空气透视，形成明确的前、中、后景空间层次。

```prompt
颗粒只在侧光、逆光、窗边光线、矿灯或阳光穿过空气时自然显现，部分颗粒缓慢漂浮、轻微旋转、上下沉降，运动速度各不相同，不能像统一方向飘动的特效粒子。光线穿过空气时允许出现非常克制、自然的 volumetric light／subtle Tyndall effect，但不要形成夸张光柱。加入轻微空气雾化和真实大气透视，使远处对比度略微下降，让人物与背景之间真正存在一层“空气”。

同时保留细腻、不规则的有机35mm胶片颗粒，但胶片颗粒与空间中的悬浮灰尘必须明确区分：胶片颗粒属于影像质感，空气颗粒必须真实存在于三维空间中并具有景深变化。配合 subtle black mist／black pro-mist diffusion，让逆光颗粒、高光和空气边缘产生非常轻微的柔化与晕染。

整体必须真实、克制、有呼吸感，禁止漫天特效灰尘、雪花状颗粒、均匀噪点、闪烁粒子、过度丁达尔、CG烟雾、鱼鳞纹、涂抹感和廉价电影滤镜感。我们当时最核心的一句话其实就是：“不是给画面加颗粒，而是让摄影机和人物之间真的有一层空气。”
```
