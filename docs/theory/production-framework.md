## 核心主题

以下是把三个视频合并后的复用流程，验收条件为本手册补充。

| 阶段 | 具体工作 | 进入下一步的条件 |
| --- | --- | --- |
| 1 故事立项 | 确定主题、关系、愿望、阻碍和结尾 | 能说清楚人物发生了什么变化 |
| 2 粗分镜和资产清单 | 拆出场景、角色年龄段、服装、关键道具、声音 | 必要资产有清单，故事能转成可见动作 |
| 3 视觉规则 | 全片风格加章节差异，确定每场光源 | 同一章节不存在互相冲突的风格要求 |
| 4 资产制作 | 角色多视图、场景正反方向、道具、声音样本 | 身份可识别，空间关系成立，声音归属明确 |
| 5 分镜定稿 | 确定构图、机位、动作过程、表演、台词和时长 | 每镜承担一个清楚的主要任务 |
| 6 代表性试片 | 测一条近景表演、一条空间调度、一条对白衔接 | 核心难点有可用样片和费用记录 |
| 7 逐镜生成 | 接入本镜所需参考，筛选版本并记录问题 | 镜头本身可用，且能接前后镜头 |
| 8 剪辑和声音 | 以故事信息与情绪选择长度和切点 | 不依赖音乐也能看懂关键因果 |
| 9 输出复查 | 选定素材超分、统一色彩、校对白和字幕 | 最终文件的脸、手、空间、声音均复查通过 |

每个镜头的提示词可以拆为：镜头任务＋角色与参考归属＋时空与场景＋构图机位＋动作过程＋微表演＋光线色彩材质＋空气＋对白环境声＋连续性＋禁用项。不要为了填满结构而给每项都写很长。
