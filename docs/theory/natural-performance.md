## 这一篇解决什么

人物为什么在这一刻变化，往往比“悲伤”“感动”“紧张”这些结果词更值得先写清楚。先确定刺激，再安排一条主要反应。

<PerformanceSequence />

## 情绪要有触发，也要有时间

V2 03:13—03:50 在分镜中加入演员表演细节：嘴唇、手部、呼吸、眼神、身体重心和真实延迟。人物先接收到外界信息，随后才发生反应；对方还没说完时，不应提前完成预设动作。

写镜头时先问：人物听见了什么、看见了什么，这件事为什么触动他。然后留出停顿，让眼神、呼吸和主要身体动作逐渐发生。多人场景中，每个人的反应时机也应有差异。

## 每镜选择一条最重要的变化

比如难过可以被拆成：听见一句话，手停一下，呼吸变浅，视线下移，尝试回应。这个顺序是整理示例，使用时仍应选择最能服务当前关系的变化。

不要把吞咽、流泪、握拳、颤抖、转头和长对白全部塞进几秒。动作超载时，优先删减或拆镜，再判断需要哪些微小反应。

## 将表演写进镜头表

| 字段 | 需要说明的内容 |
| --- | --- |
| 开始状态 | 人物原本正在做什么 |
| 触发信息 | 听见或看见了什么 |
| 第一反应 | 一个停顿、眼神或呼吸变化 |
| 主要动作 | 随后发生的身体变化 |
| 结束状态 | 下一镜需要接住什么 |

## 一段可以替换的写法

下面为整理改写示例，原画面长提示词见 O06。

```prompt
人物原本正在【开始动作】。他听见【具体信息】后，手上的动作短暂停住。
先出现【一个眼神或呼吸变化】，随后才【主要身体动作或回应】。
反应有自然延迟，情绪保持克制，结束于【下一镜需要接住的状态】。
```

验收时检查：触发有没有先发生；停顿是否符合场景节奏；观众能否从动作读出关系；所有人是否机械同步。
