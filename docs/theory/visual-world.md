## 这一篇解决什么

把“电影感”拆成可以分别检查的条件：全片风格、当前场景光线、环境材质、空气介质和影像纹理。同一个镜头里，每种描述都有自己的作用。

## 先确定全片，再处理章节差异

V1 02:02—02:45 用不同电影气质对应青春、受挫和当下等段落；V2 01:39—02:06 强调从剧本和情绪出发确定风格。参考片名之后，仍需写清色彩、反差、光源、景深、空气和人物状态。

保留贯穿全片的人物真实性和影像质感，再根据叙事调节温度、空气密度与节奏。每一镜都换一种互不兼容的影像语言，会让人物像处在不同的世界。

## 当前场景只选择一套光线逻辑

V2 02:07—02:22 展示室内白天、室内夜晚、室外阴天、室外晴天柔光四类模板。先选择与场景匹配的一类，再确认主光来自哪里、辅助光从哪里进入，以及两者的亮度关系。

例如夜间电视的反光可以变化，侧后方台灯相对稳定；这个关系比一句“高级电影光”更容易核对。不要把四类时段一起贴进同一镜头，也要检查景深、环境可辨认程度和机位要求是否冲突。

## 空气与胶片颗粒分别说明

V1 05:28—06:00、V2 02:50—03:12 讨论空气中的厚度与运动。空气介质存在于场景里，应该回答：它是什么，在哪里可见，怎样运动，数量多少。厨房热气、冷天呼气和矿井煤尘都需要合理的环境依据。

胶片颗粒属于影像纹理。它不能代替皮肤结构，也不应与前中后景中的尘埃混成均匀噪点。微尘、蒸汽、柳絮的运动也不相同，保持符合场景的数量与可见条件即可。

## 写成一页视觉规则

| 层级 | 需要确定的内容 |
| --- | --- |
| 全片 | 饱和度、反差、肤色倾向、视角和柔化程度 |
| 章节 | 情绪、时段和色温差异的剧情依据 |
| 场景 | 主光、辅助光、天气与材质 |
| 当前镜头 | 景深、空气可见区域与运动幅度 |

35mm、50mm 等是提示词中沟通视角与景深的线索；生成结果仍需检查，不能由文字认定它具有精确的真实光学参数。
