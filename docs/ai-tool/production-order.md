## 这一篇解决什么

把制作后半段连成一条线：代表性试片、逐镜生成、单变量排错、素材筛选、剪辑与声音、最终复查。每一步都有可观察的进入条件。

## 先验证最困难的镜头

V3 00:35—01:13 讲到历史项目费用与较高的抽卡效率。实际预算需要结合你自己的表演难度、多人互动、连续动作和参考开销来记录，案例中的约 500 元不能直接套用。

先选择一条近景表演、一条空间调度、一条对白衔接进行试片。它们分别暴露身份、空间和声音方面的问题。低分辨率试片可以帮助判断动作与构图，后续超分无法修复换脸、错误手指、对白归属或空间跳变。

## 一次优先修复一个问题

生成前先写清当前镜头的任务，并只调用需要的参考。失败时记录最明显的问题、已经正确的部分、这轮只调整什么，保留修改前后的版本。

| 看到的问题 | 优先回看 |
| --- | --- |
| 人物换脸、年龄漂移 | 身份与年龄版本是否混用 |
| 反打时房间变化 | 是否缺少相反方向的空间依据 |
| 声音串人 | 台词与音色是否一一对应 |
| 表演像在等指令 | 是否写清触发和反应先后 |
| 动作怎么都做不完 | 单镜任务是否超载，需要拆镜 |

更完整的对应表见[一致性检查与排错](./troubleshooting.md)。

## 成本按可用素材统计

记录生成次数、可用次数、总费用与最终可用秒数。生成可用率＝可用次数÷生成次数；有效秒成本＝总费用÷最终可用秒数。可用秒数为零时保留失败支出，单独记录这次尝试。

不同难度的镜头分别统计，预算还要留出声音、超分、剪辑和返工。

## 用剪辑完成故事和情绪

V1 04:44—05:16 把镜头节奏与内容、音乐和情绪联系起来。先决定观众此刻在等什么、知道什么、感受到什么，再选择长度与切点。

先看不用配乐时，人物的行动和关系能否被理解；再决定音乐、环境声与留白怎样进入。不要为了卡点删掉听与反应，也要核对前后镜的服装、道具、视线、天气、光线与声音。

## 交付前留下两份记录

一份是[开项、生成与交付核对表](../template/delivery-checklist.md)；另一份是自己的试片与费用记录。选定合格素材后，再做超分、色彩、字幕和最终输出复查。

单变量修改用 [T10 排错模板](../template/t10.md)，剪辑声音复核用 [T11](../template/t11.md)，费用记录用 [T12](../template/t12.md)。视频里的模型版本与软件判断属于当时经验，具体选型仍以当前项目的试片结果为依据。
