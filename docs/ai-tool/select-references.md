## 核心主题

每镜只调用当前段落所需的角色、服装、环境和声音。

## 知识点

视频要点，02:28至03:01：一段已经确定为阳光明媚的场景，只使用这一段的环境图，不同时接入无关环境，避免天气或空间被带偏。

## 实操步骤 / 教程原文重点

编导解读：参考越多不一定越稳定。参考素材之间冲突时，模型需要自行选择。每一镜应知道谁提供身份、谁提供场景、谁提供构图、谁提供声音，不要让多张参考承担同一种职责却互相矛盾。

## 个人理解总结

每镜只调用当前段落所需的角色、服装、环境和声音。 将它变成当前项目可观察、可验收的条件，比直接复制结论更有用。

本页的“编导解读”“编导建议”属于整理归纳，视频要点为转述。具体提示词应回到原画面笔记核对。
