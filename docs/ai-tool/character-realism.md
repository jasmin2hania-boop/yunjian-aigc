## 这一篇解决什么

把角色的身份依据集中成一份资产卡：外貌、年龄、服装、体态、声音和参考素材。进入每个镜头时，再选择当前段落实际需要的版本。

## 先锁定身份，再处理真实细节

V2 00:40—01:11 展示同一人物的正面、侧面、背面和上半身特写。五官、脸型、发型、体型和服装保持一致，后续镜头才有稳定的身份参照。

毛孔、皮肤绒毛、眼睑、眼周细纹、微阴影和局部色差描述不同尺度的真实信息。它们要符合人物的年龄、生活经历和当前光线，不能靠均匀噪点、锐化或统一磨皮替代结构。

原提示词中修长比例、小头部和特定肤色属于该案例的审美设定。制作儿童、老人、劳动者或其他肤色角色时，应按人物重写。

## 一个人物同时保存声音

V3 01:14—02:27 将角色和环境分开管理，并先选择角色说话的片段，提取合适音色，再连接后续镜头。多人场景需要明确每句台词属于谁、对应哪个声音参考。

声音卡记录语言、口音、音色、说话习惯和干净的样本。声音参考帮助维持身份；当前对白的哭腔、笑意、气息与停顿，仍由这场戏决定。年龄变化是否允许带来声音变化，也要提前写清楚。

## 白底资产与正式镜头分开使用

V1 02:48—03:55 涉及人物、环境和道具资产。白底四视图负责说明“是谁”，进入剧情后，照明、表情与姿态需要服从场景。把白底设定图的棚拍状态一起带进电影镜头，容易产生摆拍感。

V3 02:28—03:01 提醒当前段落只调用对应参考。每镜应知道哪份素材提供身份、哪份提供环境、哪份提供声音；无关的年龄、服装或天气版本先移出引用。

## 一份角色卡至少写清这些

- 身份编号、姓名关系、当前年龄与五官锚点。
- 当前服装、配饰、体态，以及允许随剧情变化的部分。
- 音色样本、语言口音，以及明确的说话人归属。
- 本镜使用的参考版本，和需要保持的身份特征。

检查时先看换镜头后是不是同一个人，再看皮肤细节和声音是否合理。资产稳定以后，当前分镜的表演才有清楚的执行对象。
