## 核心主题

| 问题 | 优先检查 | 第一轮修复 |
| --- | --- | --- |
| 换脸或年龄漂移 | 角色参考是否选错，文字是否混用了年龄版本 | 保留唯一身份参考，明确本镜年龄与服装 |
| 脸像塑料或蜡像 | 是否过度磨皮、锐化、均匀肤色 | 写具体皮肤结构与自然光，减少修饰词冲突 |
| 换个机位就换了房间 | 是否只有一侧场景图 | 补反方向视角并核对门窗与家具 |
| 天气昼夜突然变化 | 是否接入了其他章节的环境 | 仅保留本场图，锁定时间和主光源 |
| 声音变了或串角色 | 是否只有人像，没有声音绑定 | 接入对应声音样本，逐句写明说话人 |
| 人物像念台词 | 是否只有情绪标签，没有听与反应 | 写清刺激、停顿和一个主要身体变化 |
| 人物一起转头或动作同步 | 是否把多人写成一个集体指令 | 分角色写反应时机，留出听的过程 |
| 空气像雪或画面脏 | 是否粒子太多、匀速、全画面可见 | 限定介质、数量、光照条件与景深 |
| 上下镜接不上 | 人物位置、视线、动作阶段是否相反 | 使用站位草稿和选定的前镜参考 |
| 分辨率高但仍不可信 | 是否把结构错误当成清晰度问题 | 回到生成或剪辑修正，合格后再超分 |

建议一次只改一个优先问题，并保留修改前后版本。若镜头必须同时完成长对白、复杂走位、多人交互和剧烈情绪变化，应先考虑拆镜头，而不是无限追加限制词。
